# Protocol 01 — bounded reconciliation feasibility

Declared before study model executions, 2026-09-17. Runtime pin:
9ffb10a66180626b80127fb1892b2cf71e39d946; no runtime modifications.

Synthetic invoice/export reconciliation analogue, not a public benchmark or real
customer data. Tasks require selecting columns and interpreting monetary units,
credit direction, accepted statuses and revision precedence. A retained general
transform handles parsing, joining account mappings, deduplication and arithmetic.
Unknown accounts must remain quarantined and rejected statuses must stay excluded.
Current contracts override source examples. The retained program is authored by
the investigator before collection; do not describe it as autonomously acquired.

One history: eight source jobs (four contract vocabularies, two numeric instances),
four development jobs with recombined contracts, then twelve untouched evaluation
jobs, half revised. Original and revised jobs have different rows and IDs. They
are correlated synthetic cases, not twelve independent histories. No population
significance claim. Seeds and complete-task grading fixed in generator code.

Both principal arms inherit identical source examples, code, tools, prompts,
generation budgets and public shape/error feedback. Examples are automatically
included and also available through experience. Code can be read and directly
executed; no code regeneration required. Model selects the transformation config.
No evaluator feedback during execution. Each job starts a fresh process/workspace,
base/tokenizer and selected adapter, no conversational or optimizer state.

Collector: pinned base model with these tools. Eight source attempts are retained.
Investigator-authored source reference actions are executed and checked separately,
including finish. They are disclosed supervision, not model-generated successes.
Source examples are available externally before collection as authored working
references; collection tests behavioral baseline, not autonomous discovery.
Only source reference traces may enter training. Development grades may select
recipe, never training targets. Evaluation public payloads and labels are generated
only after a selection decision. Evaluator runs in controller only; worker receives
only task JSON, state, code and external source references, never expected outputs.

First recipe: native rank-8 last-eight-layer Q/V LoRA, runtime default seed17,
AdamW 0.0005, target-only loss, 32 updates. Acquisition check: source and dev
complete tasks, not loss alone. If no source improvement and source baseline has
failures, diagnose trace failure and train a 96-update restart from base on the
same source data. If already at ceiling, train 96 only if 32 regresses. At most two
recipes here; substantive new recipes need a separately recorded development plan.
Select highest development complete count, ties use fewer updates. Source gain is
reported separately. An adapter is not called an acquired useful treatment unless
it corrects at least one previously failed source job without lowering dev total.
A ceiling or failed acquisition remains a limitation, never a transfer-null claim.

After decision, compare base reuse and the selected diagnostic adapter on all
12 fresh jobs regardless of sign. Record changed-task exact completion and each
output component, including preserved exclusions/quarantine. Repeat one base job
after adapter use to check reset. Direct deterministic execution with authored
correct config provides a tool/evaluator check, not a competing neural condition.

No remote training or large search. Initial training limited by runtime to 16 GiB
MLX allocation, one model worker at a time, 6 action turns per job. Remote serving
smoke is feasibility only. Token, tool, worker wall and training counts remain
separate. All failed work is charged; development search separate from deployment.
Authoring agent tokens/labor, energy and FLOPs unknown. No timing speedup claim on
shared hardware. No separate paid teacher calls; investigator authored corrections
are teacher work with unknown authoring cost.
